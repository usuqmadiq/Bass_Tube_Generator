# Детали сборки

Эти файлы генератор не строит. Их печатают и собирают вместе с трубой из окна.

| Файл | Зачем |
|---|---|
| `head.stl` | Модуль мембраны. Конец трубы входит в его отверстие. |
| `ring.stl` | Кольцо к модулю. |
| `двойной мундштук.step` | Насадка на две мембраны (мелодия и дрон). Оси входов трубы — 48 мм. |
| `сетка.step` | Сетка к сборке. |
| `5_hole_bass_tube(2).stl` | Референс исходной трубы с пятью отверстиями. |

Форматы: STL — сетка на печать, STEP — твёрдое тело для CAD.
